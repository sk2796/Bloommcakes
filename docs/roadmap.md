# Roadmap

Project implementation milestones for the Bloomcakes application.

## Phase 1: Project Foundation (Completed)
* React + TS + Vite framework setup
* Tailwind CSS configuration
* Feature routing architecture and placeholder screens
* Supabase client integration layer
* TanStack Query structure & test environment configurations

## Phase 2: Design System & Styling (Upcoming)
* Set up global visual design variables (HSL color spaces, typography scales)
* Integrate UI library components (shadcn/ui layout widgets)
* Theme configuration patterns (light/dark mode toggle support)

## Phase 3: Core Commerce Flow
* Product list & product detail layout screens
* Add to Cart & Shopping Cart operations logic (Zustand client store sync)
* PIN code validation & same-day delivery slots checks

## Phase 4: Custom Cake Builder
* Ocassion, size, shape, flavor, filling selections
* Reference sketch uploads, custom cake instructions input
* Delivery slot scheduler

## Phase 5: Checkout & Integration
* Address input, checkout forms validation
* Razorpay payment gateway client scripts integration
* Order status, order receipt, delivery maps trackers

## Phase 6: Admin Dashboard & Operations
* Order queues tracking lists
* Product and stock level management tables
* Custom cake custom design review dashboards
