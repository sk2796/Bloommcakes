# Artisanal Confectionery System - Design Specification

This document specifies the design tokens, brand identity, and theme system for the **Bloomcakes** web application.

## Brand & Style
* **Philosophy**: "Beautifully Crafted, Happily Celebrated"
* **Personality**: Warm, elegant, deeply appetizing. Evokes comfort, joyful celebration, and artisanal baking craftsmanship.
* **Aesthetic**: Modern Professional with Tactile Warmth. Cream-based background layers paired with organic typography and soft rounded surfaces.

## Colors
* **Primary**: `#865300` (Warm Sun-kissed Amber/Orange) / Container Tint `#ffba65`
* **Secondary**: `#775652` (Deep Chocolate Brown)
* **Background/Tertiary**: `#fff8f6` (Soft Cream White)
* **Error**: `#ba1a1a`

Full HSL-based palette maps directly into the Tailwind configuration.

## Typography
* **Poppins**: Structural headings (Display, Headline) - clean, geometric.
* **Lato**: Functional body text, forms, labels - readable, friendly.
* **Dancing Script**: Accent font layer (taglines, hand-crafted callouts).

## Rounded Corners (Shape Language)
* **sm**: `0.25rem` (4px)
* **DEFAULT**: `0.5rem` (8px)
* **md**: `0.75rem` (12px)
* **lg**: `1rem` (16px)
* **xl**: `1.5rem` (24px)
* **full**: `9999px`

## Elevation & Depth
* **Shadow Tint**: Diffused chocolate-based shadow: `0px 10px 30px rgba(119, 86, 82, 0.08)`
