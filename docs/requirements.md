# Requirements

This document tracks target features and scope requirements for Bloomcakes.

## Core Features & Offerings
* **Product Catalog**: Cakes, pastries, cupcakes, brownies, cheesecakes, dessert jars, celebration products.
* **Product Configurations**: Custom size variants, weights, flavors, custom message tags, Egg/Eggless option selectors.
* **Custom Cakes**: Theme uploads, customized shapes, sizes, frosting types, custom filling flavors, and reference sketch/image configuration.
* **Order Flow & Commerce**: Shopping Cart system, Razorpay checkout gateway, order validation pipelines.
* **Logistics & Delivery**: Customer address validation, PIN code validation parameters, same-day delivery schedules, store pick-ups.
* **Operational Dashboards**: Product, order, inventory, delivery tracking systems.

## Quality Standards
* **A11y Compliance**: Target WCAG 2.2 AA (semantic layouts, proper labels, aria properties, contrast limits).
* **Performance Targets**: Under 2.0s Largest Contentful Paint (LCP) time, minimal JS bundle sizes, dynamic rendering controls.
* **Mobile-First Layout**: Adaptive responsive structure across mobile, tablet, and desktop display environments.
